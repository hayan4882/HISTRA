# HISTRA · 유물 3D 탐색기

## 바로 실행

압축을 푼 뒤 `index.html`을 브라우저에서 여세요. Three.js 엔진과 세 3D 모델을 HTML 안에 포함해, 별도 `models/` 폴더나 웹 서버 없이 실행할 수 있습니다. 브라우저에서 WebGL이 활성화되어 있어야 합니다.

`.glb` 파일은 웹페이지가 내부에서 불러오는 3D 에셋이지, 일반 브라우저에서 직접 여는 페이지가 아닙니다. `index.html`을 열어 사용하세요.

## 조작

- 마우스 이동: 조각상이 포인터를 따라 회전하고 표시 지점도 조각과 함께 움직임
- **회전 멈추기** 버튼: 회전 정지, 마우스로 핫스폿을 편하게 선택
- **회전 다시 시작** 버튼: 포인터 추적 회전 재개
- 빛나는 동그라미 선택: 해당 부분의 역사 설명 보기
- 스크롤 또는 작품 목록 선택: 다음 조각으로 이동

## 포함 작품

- 카피톨리노 늑대상
- 라오콘 군상
- 아폴로 벨베데레상

아우구스투스 프리마 포르타상은 이 탐색기에서 제외했습니다. 카피톨리노 늑대상·라오콘 군상·아폴로 벨베데레상은 참고 자료를 바탕으로 제작한 회전 가능한 3D 모델입니다.

## Religion · Daily Life

- **Religion:** 성 베드로 대성당, 판테온, 시스티나 성당의 실제 사진을 대형 비대칭 갤러리로 탐색합니다.
- **Daily Life:** 에스프레소 바, 역사적 광장, 지역 식탁을 서로 다른 크기의 사진 콜라주로 보여 줍니다.
- 스크롤 시 사진이 자연스럽게 등장하고, 이미지에 마우스를 올리거나 클릭하면 장소와 생활문화 설명이 나타납니다.
- 위 여섯 사진은 HTML에 포함되어 있어 별도 이미지 폴더나 서버 없이 사용할 수 있습니다.
